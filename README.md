# Doer — планировщик дня

Лёгкое приложение для планирования дней в стиле TickTick. Без сборки и зависимостей: откройте `index.html` в браузере. Данные хранятся в `localStorage`.

- Представления: Сегодня, Завтра, Ближайшие 7 дней, Все задачи, Календарь, Выполнено
- Свои списки (`+` в боковой панели; правый клик / долгое нажатие — переименовать или удалить)
- Подзадачи, приоритеты, дата и время, заметки, поиск
- Быстрый ввод: `Встреча завтра в 15:00 !2 #Работа` (даты: сегодня/завтра/послезавтра/в пятницу/25.12; `!1–!3` приоритет; `#список`)
- Тёмная тема, адаптив под телефон
