# Күнім — планировщик дня

Планировщик в стиле TickTick: Сегодня / Завтра / 7 дней / Календарь, списки, подзадачи, приоритеты, повторы, напоминания, быстрый ввод (`Встреча завтра в 15:00 !2 #Работа`), тёмная тема. Работает как PWA (ставится на телефон и ноутбук) и синхронизируется между устройствами.

## Запуск
```
node server.js        # Node 18+, без зависимостей; PORT=3000, DATA_DIR=./data
```
Откройте `http://localhost:3000`. Для телефона сервер должен быть доступен из интернета по **HTTPS** (нужно для установки PWA и уведомлений) — разверните на любом хостинге с Node (Render, Railway, Fly.io, VPS) или за Cloudflare Tunnel. Хранилище — папка `DATA_DIR` (на хостинге подключите постоянный диск).

## Синхронизация
На каждом устройстве: кнопка «☁ Синхронизация» внизу меню → введите один и тот же ключ (≥ 8 символов, это ваш «пароль»: по нему на сервере выбирается ваше хранилище). Слияние по задачам, побеждает последнее изменение; офлайн работает, синхронизируется при появлении связи.

## Установка на телефон
iPhone: Safari → Поделиться → «На экран Домой». Android: Chrome → «Установить приложение».

## Напоминания
Срабатывают, пока приложение открыто (или свёрнуто, но живо) — уведомления браузера + плашка. Push при полностью закрытом приложении не реализован.
